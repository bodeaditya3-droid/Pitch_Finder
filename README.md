
# Pitch Finder

A Python-based real-time pitch detection project that analyzes microphone
input and detects the fundamental frequency (pitch) of a person's voice.

## Status

🚧 In Progress

## Current Features

- Real-time microphone input
- Audio waveform visualization
- Pitch/frequency detection
- Basic real-time processing

## Planned Features

- More sensitive pitch detection
- Improved accuracy
- Real-time frequency display
- Note identification (C, C#, D, etc.)
- Better visualization
- Noise filtering

## Technologies

- Python
- NumPy
- SoundDevice
- Matplotlib

## How to Run

```bash
pip install -r requirements.txt
python src/pitch_detector.py
